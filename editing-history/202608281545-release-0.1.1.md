# 发布 0.1.1 / Release 0.1.1

## 中文

- 发布同步 EDN 导出宏，供多方法 native 模块消除重复 C wrapper。
- 保持 buffer 与 async/blocking protocol 均为 v1，属于向后兼容的小版本更新。

## English

- Release the synchronous EDN export macro for multi-method native modules.
- Buffer and async/blocking protocols remain at v1; this is a backward-compatible patch release.
