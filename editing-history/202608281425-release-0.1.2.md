# 发布 0.1.2 / Release 0.1.2

## 中文

- 发布供 Calcit host 与 native module 共用的 raw ABI symbol、function pointer、descriptor 与 resource token 常量。
- C ABI protocol 仍为 v1；host-owned registry、lease 与 lifecycle 行为不变。

## English

- Release shared raw ABI symbols, function pointers, descriptors, and resource-token constants for the Calcit host and native modules.
- The C ABI protocols remain at v1; host-owned registry, lease, and lifecycle behavior is unchanged.
