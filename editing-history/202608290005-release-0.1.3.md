# 发布 0.1.3 / Release 0.1.3

## 中文

- 默认异步背压改为每 1ms 重试、最长等待 5 秒，避免 host 队列持续饱和时永久占住 native worker。
- 发布 raw payload `enqueue_with_backpressure_until` 与 EDN `publish_emit_until`，让普通事件在等待队列容量时响应模块自有取消状态。
- 保持 C ABI protocol v1 不变；terminal `complete` / `fail` 继续通过普通 helper 利用 host 预留容量可靠收尾。

## English

- Change default async backpressure to 1ms retries with a five-second maximum wait, preventing permanently saturated host queues from retaining native workers forever.
- Release raw-payload `enqueue_with_backpressure_until` and EDN `publish_emit_until`, allowing ordinary events to observe module-owned cancellation while waiting for queue capacity.
- Keep C ABI protocol v1 unchanged; terminal `complete` / `fail` events continue through regular helpers and host-reserved terminal capacity for reliable cleanup.
